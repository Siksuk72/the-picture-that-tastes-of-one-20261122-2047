One picture of food, built on a single ingredient: a glistening chunk of
golden honeycomb with thick amber honey dripping off it, on dark slate,
in warm light. The honeycomb fills the frame, the honey shines, and the
whole picture still reads delicious at ~300 px. `main.py` (Python 3.13,
stdlib only, no network) copies the bundled picture to
`/output/entry.png` for the grader, after checking it is a whole PNG of
at most 1,048,576 bytes and 1024 by 1024 pixels.

## Run it

```sh
python3 main.py
```
